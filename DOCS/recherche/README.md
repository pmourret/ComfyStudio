# DOCS/recherche/ — Notes de recherche et d'inspiration

Un fichier par session de recherche, daté : `AAAA-MM-JJ-sujet-court.md`.
Contrairement à `DOCS/cadrage/`, ces fichiers ne portent pas de décision
prise en commun avec l'utilisateur — ce sont des relevés d'observation sur
une source externe (un pack ComfyUI, un outil tiers, une référence visuelle)
consignés pour irriguer les décisions futures. Un fichier n'est pas remis à
jour après coup : une nouvelle passe sur le même sujet ouvre un nouveau
fichier.

**Ce ne sont pas des documents de référence à jour.** Une note qui cite un
chemin, une version de modèle ou un nom d'outil décrit un état observé à la
date du fichier — à revérifier avant de s'appuyer dessus si le temps a
passé. Les décisions qui naissent de ces notes sont formalisées ailleurs :

- Idées retenues à explorer : `DOCS/ideas/`
- Le pourquoi d'une décision structurante, avec les alternatives écartées :
  `DOCS/adr/`
- Le séquencement (quoi, quand) : `ROADMAP.md`
