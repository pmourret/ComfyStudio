# DOCS/handoffs/

Un fichier par session de travail notable (jalon de roadmap ou tâche
significative), écrit par Claude Code à la fin de sa session. Objectif :
que la session suivante reprenne en lisant ce fichier plutôt qu'en
recevant le rapport complet retapé dans le prompt.

Convention : AAAA-MM-JJ-nom-court.md — état atteint, fichiers touchés,
décisions prises, ce qui reste ouvert, prochaine étape attendue.

Différent des ADR (pas une décision structurante à tracer dans la durée)
et du cadrage (pas de vision) — un état des lieux, utile pour la
continuité puis pour l'historique, jamais réécrit après coup.
