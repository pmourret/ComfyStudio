## État atteint

Le frontend, resté 7 fichiers `<script>` classiques partageant ~35 variables
globales implicites, est passé en modules ES sans étape de build : **aucune
globale partagée entre fichiers** (CLAUDE.md §9), chaque donnée encapsulée dans
le module qui la possède, réactions inter-modules par un bus d'événements.
`app.css` est scindé, avec une couche de tokens comme seule couture d'identité
visuelle. Le sélecteur `?character=` est enfilé de bout en bout, backend
compris.

### Étape 1 — bascule en modules ES (mécanique, comportement identique)

- `index.html` : 7 `<script>` → un seul `<script type="module" src="/static/main.js">`.
- Feuilles sans état : `dom.js` (`$/$$/esc/mmss`), `api.js` (`api/post/erreurDe`),
  `constants.js` (`VERDICT_LABEL/ROUTES`), `bus.js` (posé pour l'étape 2).
- `store.js` **transitoire** : les ~35 variables partagées sous un objet `S`
  unique ; `LEVEL` → `S.LEVEL`, ~230 substitutions mécaniques.
- `boot.js` supprimé → `poller.js` (`tick`/`refreshCounts`) + `main.js`
  (séquence d'init, ordre historique de `index.html` préservé). Gardes
  `typeof X === 'function'` remplacées par des imports.
- `test_panneau_reglages.js` / `test_scenes_aller_retour.js` : migrés de
  `eval(fichier)` vers `import()` (le stub pose `document.querySelector`, sur
  lequel `dom.js` repose). `test_application_suppression_editeur.js` : les
  assertions lisant `ED_CROP`/`ED_ROT` dans le scope global lisent maintenant
  la géométrie rendue de `#edCropBox`/`#edCanvas`.

### Étape 2 — encapsulation de l'état, `store.js` dissous

- `core.js` scindé : `nav.js`, `toast.js`, `modal.js`, `lightbox.js`,
  `health.js` (bandeaux panne + dirty ; `PANNES` privé).
- Trois modules d'état extraits, chacun charge ses données et émet :
  `config.js` (`QC/PRESET_REF/NSFW_REF` + `loadConfig` = ex-`loadQc`) →
  `config:loaded` ; `taxonomy.js` (`CREATIVE` + `loadCreative` + `palier`) →
  `creative:loaded` ; `scenes-store.js` (`SC/SC_DIRTY` + `loadScenes` +
  `setDirty`) → `scenes:loaded` / `scenes:dirty`.
- Les repeints qui suivaient un chargement deviennent des `bus.on(...)` dans
  `create.js` / `review.js` / `advanced.js` / `health.js`. Plus d'appel
  explicite à `majDirty()`.
- État par écran, privé au module : `create.js` (`SEL/INTENT/TONE/LEVEL/…`,
  expose `planOk()`), `review.js` (`BUCKET/SPACE/VIEW/…`, expose
  `triageState()` + `setTriageEntry()`, `syncTriageUi` rapatrié ici),
  `advanced.js` (`PROPS/JROWS/JFILTER`), `poller.js` (`RUNNING/LASTBATCH`,
  expose `isRunning()`/`markRunning()`).
- 2 boutons d'état-vide de la Revue avaient encore `onclick="go('creer')"`
  inline (dépendance à un global, latente depuis l'étape 1) — câblés en
  `addEventListener`.
- `store.js` et `core.js` supprimés.
- Ordre des abonnements bus : `create` avant `advanced` pour `scenes:loaded`,
  garanti par la chaîne d'imports `nav → review → create` évaluée avant
  `import './advanced.js'` dans `main.js`.

### Étape 3 — design system minimal, `app.css` scindé

- `app.css` (554 l.) → `tokens.css` (**seule couche d'identité visuelle** :
  palette, typo, forme) + `base.css` + `components.css` + `screens.css`
  (chargé en dernier). Découpage **contigu** : ordre des règles conservé (0
  sélecteur dupliqué dans `app.css`, vérifié) → cascade identique.
- Reconstruction vérifiée : `base+components+screens` avec les `var()`
  réexpandés == corps de l'ancien `app.css` (aux seuls écarts attendus : plus
  de valeurs passent par `var()`, 2 lignes vides de séparation en moins).
- Tokens ajoutés, tous égaux à la valeur en dur remplacée (zéro pixel) :
  `--on-acc`, familles `--warn-*` / `--danger-*` / `--mes-*`, `--font`,
  `--font-mono`, `--maxw`. Restent bruts en V1 (documenté) : élévations,
  scrims, ambiances ponctuelles, rayons de contrôle secondaires.
- `DESIGN.md` : contrat de tokens + inventaire des composants.

### Étape 4 — sélecteur `?character=` de bout en bout

- `character.js` : lit `?character=` (défaut `lena`), figé au chargement.
  `api.js` : `api()`/`post()` ajoutent `character=<id>` à chaque appel
  `/api/*` — seul point de passage. `/img` / `/static` non touchés.
- `shared_state.character(request)` : valide un slug simple **et**
  l'existence de `CHARACTERS/<id>/` **avant** tout accès disque —
  `?character=../x` sort en 400 JSON, jamais en 500 ni en chemin.
  `cfg()`/`scenes_data()` prennent `character` (défaut `lena`).
- `routes/etat.py`, `banque.py`, `production.py` : les ~25 `"lena"` en dur des
  handlers de données de personnage remplacés par `character(request)`,
  enfilé à travers la chaîne d'aide de `production.py` en kwarg défaut
  `"lena"`. `STATE["character"]` posé par `demarrer*` ; `duree_unitaire()` le
  relit.
- Aucun `if character == "lena"` : seul le **défaut** vaut `"lena"` (§8.7).
- `test_character_param.py` (nouveau, §11) : `CHARACTERS/probe/` jetable,
  isolation lecture ET écriture prouvée, 6 ids invalides → 400 JSON.
